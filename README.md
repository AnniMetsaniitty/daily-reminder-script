# Daily Reminder Script

This PowerShell script helps you set up a simple daily reminder on your Windows machine.

## 📝 Purpose

The script is designed to automate the creation of daily reminders—ideal for keeping track of habits, tasks, or appointments. Once configured, it can send you a custom pop-up message at a specified time each day.

## ⚙️ How It Works

- You define the reminder message and time
- The script schedules a Windows Task using Task Scheduler
- A notification appears daily at your chosen time

## 🚀 Getting Started

1. Clone or download this repository.
2. Run the `daily-reminder.ps1` script in PowerShell with administrator privileges.
3. Follow the prompts to set your reminder.

> 💡 Make sure PowerShell script execution is allowed on your system (`Set-ExecutionPolicy`).

## 📌 Note

This script is intended for personal use on Windows systems that support Task Scheduler and PowerShell.

---

Feel free to adjust the message, time, or behavior in the script to fit your daily routine.
